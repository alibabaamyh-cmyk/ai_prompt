# 旺舖定位 Prompt 庫

根據商家優勢和目標市場，自動生成旺舖定位文案。

## 包含的場景
- 品牌商家
- 工廠/製造商
- 貿易商/代理商
- 中小企業主
- 個人賣家

## 使用方式
1. 選擇對應的商家類型
2. 填入商家信息（品牌名、優勢、目標市場等）
3. 複製 Prompt 到 Claude
4. 獲取定制化的旺舖定位文案

## Prompt 變數
- `{brand_name}` - 品牌/公司名稱
- `{main_products}` - 主要產品類別
- `{unique_advantage}` - 獨特優勢
- `{target_market}` - 目標市場
- `{price_point}` - 價格定位
- `{company_experience}` - 公司經驗/成立年份
