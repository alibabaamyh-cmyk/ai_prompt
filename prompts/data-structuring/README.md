# 資料結構化 Prompt 庫

幫助工廠和貿易商快速將非結構化的產品資料（Excel、PDF、圖片）轉換為標準化的結構化數據。

## 使用場景
- 從 Excel 檔案整理產品信息
- 從 PDF 檔案提取商品描述
- 將多個數據源合併
- 標準化不同格式的商品資料

## 輸出格式
- Excel/CSV（用於上傳系統）
- JSON（用於 API）
- 結構化文本

## 包含的場景
- 工廠/製造商
- 貿易商/代理商
- 中小企業主

## Prompt 變數
- `{file_format}` - 文件格式（Excel、PDF 等）
- `{data_content}` - 實際數據內容
- `{output_format}` - 輸出格式要求
