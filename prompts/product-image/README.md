# 產品主圖 Prompt 庫

生成符合國際站風格（900×900）的產品主圖 AI Prompt。

## 特點
- 專為阿里巴巴國際站優化
- 支持批量生成多個風格變體
- 包含構圖、配色、文案等建議
- 適用於各類商品

## 包含的商品類別
- 服飾和配件
- 家居和日用品
- 美妝護膚
- 電子和機械
- 食品和飲料
- 手工藝品

## 使用方式
1. 選擇商品分類
2. 填入商品信息（名稱、顏色、材質等）
3. 複製 Prompt 到 Claude 或 Midjourney
4. 調整生成結果

## 注意事項
- 尺寸規格：900×900px
- 背景：通常為白色或淡色
- 風格：專業、清晰、吸引眼球
- 文字：盡量少，主要展示產品
