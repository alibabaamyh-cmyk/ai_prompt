# 商品詳情頁 Prompt 庫

根據商品特色和賣點，自動生成切中買方市場、有競爭優勢的商品詳情文案。

## 包含的場景
- 品牌商家
- 工廠/製造商
- 貿易商/代理商
- 中小企業主
- 個人賣家

## 使用方式
1. 選擇對應的商家類型
2. 填入商品信息（名稱、特色、規格、價格等）
3. 複製 Prompt 到 Claude
4. 獲取優化後的商品詳情文案

## Prompt 變數
- `{product_name}` - 商品名稱
- `{product_category}` - 商品分類
- `{product_features}` - 商品特色/賣點
- `{specifications}` - 商品規格
- `{price_point}` - 價格定位
- `{target_customer}` - 目標客戶
- `{competitive_advantage}` - 競爭優勢
- `{use_cases}` - 應用場景
