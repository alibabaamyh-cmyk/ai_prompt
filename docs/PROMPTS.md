## 🎯 快速開始

### 步驟 1：識別你的商家類型

- **品牌商家** 🎁 — 有自主品牌，需要打造高端形象
- **工廠/製造商** 🏭 — 有生產能力，需要B2B銷售文案
- **貿易商/代理商** 📦 — 代理多個品牌，需要快速上架
- **中小企業主** 🏪 — 傳統生意轉線上
- **個人賣家** 👤 — 小規模經營

### 步驟 2：選擇需要的 Prompt 類型

1. **旺舖定位** — 生成店舖介紹和定位文案
2. **商品詳情頁** — 生成商品描述和文案
3. **產品主圖 Prompt** — 為 AI 圖像工具生成圖片 Prompt
4. **資料結構化** — 整理非結構化的商品資料

### 步驟 3：複製對應的 Prompt 模板

### 步驟 4：填入你的信息

- 替換所有 `{變數}` 為你的實際信息
- 提供盡可能詳細的信息，結果會更好

### 步驟 5：使用 Prompt

- 粘貼到 Claude（或其他 AI 工具）
- 等待生成結果
- 根據需要調整和優化

## 📖 詳細 Prompt 說明

### 1. 旺舖定位 Prompt 🏪

**用途**：生成專業的店舖介紹和定位文案

**適用商家**：品牌商家、工廠、貿易商

**包含的 Prompt 類型**：

#### 品牌商家
- **品牌介紹文案** — 旺舖首頁的品牌介紹（200-300字）
- **店舖詳情描述** — 「關於我們」詳細介紹（400-500字）
- **產品系列介紹** — 各產品線的特色說明（300-400字）
- **品牌價值主張** — 品牌的核心價值和承諾（200-250字）

#### 工廠製造商
- **工廠介紹** — 專業的工廠介紹（350-450字）
- **生產能力說明** — 詳細的產能和優勢（400-500字）
- **品質保證承諾** — 品質體系和承諾（300-400字）
- **合作優勢** — 與工廠合作的優勢（350-400字）

**使用示例**：
```
場景：你是一個護膚品品牌
Prompt 類型：品牌商家 > 品牌介紹文案
填入信息：
- {brand_name} = "AMY Beauty"
- {brand_story} = "源於大自然的護膚理念，致力於..."
- {target_market} = "亞洲、歐洲高端市場"
- {price_point} = "高檔"
- {unique_advantage} = "天然成分、無添加、5年品牌歷史"

複製 Prompt 並填入信息，粘貼到 Claude。
結果：高質量的品牌介紹文案
```

### 2. 商品詳情頁 Prompt 📝

**用途**：生成吸引買家的商品詳情文案

**適用商家**：所有類型

**包含的 Prompt 類型**（通用版本）：

- **商品標題優化** — SEO 友好的商品標題（3-5個變體）
- **商品概述** — 簡潔的商品介紹（50-100字）
- **商品詳細描述** — 完整的商品描述（300-400字）
- **產品優勢說明** — 競爭優勢分析（200-300字）
- **常見問題解答** — Q&A 內容（8-10個問答對）
- **購買指南** — 幫助客戶選擇（150-200字）

**使用示例**：
```
場景：你要銷售一款抗皺面霜
Prompt 類型：商品詳情頁 > 商品詳細描述
填入信息：
- {product_name} = "深層修復抗皺面霜"
- {specifications} = "50ml，適合30+膚質"
- {product_features} = "含視黃醇、透明質酸、人蔘提取物"
- {price_point} = "中高端"
- {target_customer} = "30-50歲女性，關注抗衰老"
- {competitive_advantage} = "3個月見效、不油膩、持久保濕"

結果：詳細、有說服力的商品描述
```

### 3. 產品主圖 Prompt 🖼️

**用途**：為 AI 圖像工具生成產品主圖 Prompt

**適用工具**：Midjourney、DALL-E、Stable Diffusion

**包含的 Prompt 類型**：

- **服飾類主圖** — 衣服、配件等
- **家居/日用品主圖** — 家居、生活用品
- **美妝/護膚品主圖** — 化妝品、護膚品
- **電子產品主圖** — 3C 產品
- **批量生成指南** — 多個產品的快速生成方法

**特殊說明**：
- 尺寸：900×900px（國際站標準）
- 背景：純白色或淡色
- 風格：專業、清晰、高質感

**使用示例**：
```
場景：你要為 5 個美妝產品生成主圖
Prompt 類型：產品主圖 > 批量生成指南

結果：
1. 一個可復用的 Prompt 模板
2. 為每個產品填入具體參數的 Prompt
3. 使用建議和質量檢查清單

然後在 Midjourney 中：
/imagine [Prompt for Product 1]
/imagine [Prompt for Product 2]
... 等等
```

### 4. 資料結構化 Prompt 📊

**用途**：快速整理非結構化的商品資料

**適用場景**：
- Excel 檔案有很多商品，格式混亂
- PDF 說明書中有很多產品信息
- 多個數據來源需要合併
- 要為大量商品建立標準目錄

**包含的 Prompt 類型**：

- **Excel 資料結構化** — 整理混亂的 Excel
- **PDF 資料提取** — 從 PDF 中提取產品信息
- **多源資料合併** — 合併多個來源的數據
- **產品目錄構建** — 建立標準化產品目錄
- **商品圖片元數據提取** — 從圖片識別商品信息

**使用示例**：
```
場景：你是一個工廠，有 200 個產品的 Excel，格式很混亂
Prompt 類型：資料結構化 > Excel 資料結構化

步驟：
1. 複製 Excel 內容（或描述檔案內容）
2. 粘貼到 Prompt
3. 提交給 Claude
4. 獲得結構化的 CSV/Excel 檔案

結果：
- 所有 200 個產品的標準化數據
- 包括中英文描述
- 符合國際站上傳要求
```

## 💡 最佳實踐

### ✅ 良好的 Prompt 使用

1. **詳細填入信息**
   - 不要跳過任何變數
   - 提供具體的數據而不是模糊描述
   - 包含數字、日期、具體例子

2. **清晰表達你的需求**
   - 說明輸出的用途（在哪個平台發佈）
   - 指定文字長度要求
   - 說明目標客群

3. **評估和修改結果**
   - 第一次生成的結果可能不完美
   - 可以要求 Claude 調整、簡化或擴展
   - 根據需要進行迭代改進

### ❌ 常見錯誤

1. **信息不完整**
   - 導致生成的內容不夠准確
   - 結果可能不符合預期

2. **要求不清晰**
   - 沒有說明用途和目標客群
   - 導致內容風格不匹配

3. **一次性使用**
   - 只用一個 Prompt 就放棄
   - 應該根據結果進行調整和改進

## 📝 提示和技巧

### 如何改進生成的內容

如果生成的內容不完美，可以這樣做：

1. **請求調整風格**
   ```
   生成的文案有點過於正式，能否改成更親切、友好的語氣？
   ```

2. **加入更多細節**
   ```
   能否加入更多關於產品工藝的細節？
   ```

3. **強調某些方面**
   ```
   能否更強調產品的環保特性？
   ```

### 如何為多個產品快速生成內容

1. 建立一個 Prompt 模板
2. 為每個產品填入不同的信息
3. 使用 Claude API 或批量功能進行處理
4. 統一格式和風格
